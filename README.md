# Batimatch Pilotage

Application de pilotage du réseau Batimatch.

## Principes

- Airtable reste la source de vérité.
- Batimatch Pilotage lit les données des 8 tables métier actives.
- La table `Cotisations ( A SUPPRIMER )` est ignorée.
- Les accès Airtable doivent rester côté serveur.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
